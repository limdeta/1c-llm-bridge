# Первый день на новом стенде

Процедура для агента, который получил доступ к виртуальной машине с 1С и тестовой базой.
Машина — наша: на ней можно ставить что нужно. Ограничение не в машине, а в **правах роли
пользователя ИБ** и в том, что за машиной смотрит администратор.

## 0. Где что крутится

- **Агент и его харнес** — на Windows Server (наш VPS), PowerShell там рабочий.
- **Мост к 1С — на виртуальной машине с 1С.** COM (`V83.COMConnector`) существует только там,
  где установлена платформа; «по сети» к нему не подключиться.
- Значит, схема такая: харнес на VPS → `ssh` на VM → там работает мост → результат обратно.
  На VPS можно ставить Node, .NET, Python — но сам мост это не заменяет.

## 1. Инвентаризация VM (только чтение, ничего не меняет)

```powershell
ssh <vm> "powershell -NoProfile -Command `"$PSVersionTable.PSVersion.ToString()`""
ssh <vm> "dir `"C:\Program Files\1cv8`""
ssh <vm> "python --version"          # может отсутствовать — это нормально
ssh <vm> "dotnet --list-runtimes"    # нужно только для C#-моста
ssh <vm> "powershell -NoProfile -Command `"Get-ExecutionPolicy -List`""
```

## 2. Выбор канала

PowerShell есть на обеих машинах, поэтому базовый путь — `bridge/onec.ps1`, ничего ставить
не нужно. Остальное — запасные варианты, если упрёмся:

| Ситуация | Чем работаем |
|---|---|
| Обычная VM с 1С | `bridge/onec.ps1` через ssh (или `bridge/remote.ps1` прямо с VPS) |
| Политика запрещает .ps1, exe разрешены | `bridge/bin_fd/onec.exe` (+ .NET Runtime, можно доустановить) |
| .NET тоже нет и ставить нельзя | самодостаточный `bridge/bin/onec.exe` (~73 МБ, копируется по ssh) |
| Нужен MCP для харнеса | venv на VM + `bridge/mcp_server.py` (см. §6) |
| **Запрещён COM целиком** (AppLocker) | **стоп**: это вопрос к администратору, обходить не пытаемся |
| **Роль не даёт читать объект** | **стоп**: сформулировать, какое право нужно (см. §7) |

## 3. Развёртывание (копируем только нужное)

```powershell
scp -r bridge build setup.ps1 apply_extension.ps1 ИИМост.cfe <user>@<vm>:C:/1c-bridge/
```

Не копируем: `sandbox/` (полигон, нужен только на нашей машине), `cc-1c-skills/`, `.venv/`.

## 4. Регистрация COM (один раз, без прав администратора)

```powershell
ssh <vm> "powershell -NoProfile -File C:\1c-bridge\bridge\setup_com.ps1"
```

Установщик платформы не регистрирует `V83.COMConnector` — без этого шага подключения не будет.
Регистрация идёт в `HKCU`, поэтому права администратора не нужны.

## 5. Расширение-исполнитель (один раз, человек с правами конфигуратора)

```powershell
ssh <vm> "powershell -NoProfile -File C:\1c-bridge\apply_extension.ps1 -InfoBaseServer <srv> -InfoBaseRef <база> -UserName <админ> -Password <пароль>"
```

Нужен монопольный режим. Если администратор не разрешает применять расширение — **стоп и
спросить**: альтернатива (внешний EPF со снятой «Защитой от опасных действий») расширяет
доступ, и решение не наше.

## 6. Проверка канала

```powershell
# 1) базовый путь
ssh <vm> "powershell -NoProfile -File C:\1c-bridge\bridge\onec.ps1 -ConnectionString 'Srvr=""srv"";Ref=""база"";Usr=""имя"";Pwd=""""' check"

# 2) если PowerShell-скрипты запрещены — тот же check через exe
ssh <vm> "C:\1c-bridge\bridge\bin_fd\onec.exe check -cs ""Srvr=srv;Ref=база;Usr=имя;Pwd="""

# 3) MCP (если нужен харнесу)
```

Ожидаемый результат: исполнитель отвечает `6*7 = 42`, запросы работают, «Мост готов к работе».

**MCP через SSH.** Харнес запускает сервер по ssh-stdio:
`{"command":"ssh","args":["<vm>","C:/1c-bridge/mcp_vm.cmd"]}`. Строку соединения через `env`
передать нельзя (грабля № 55 в `PITFALLS.md`), поэтому на VM кладётся обёртка:

```bat
@echo off
set ONEC_CONNECTION_STRING=Srvr="srv";Ref="база";Usr="имя";Pwd=""
C:\1c-bridge\.venv\Scripts\python.exe C:\1c-bridge\bridge\mcp_server.py
```

## 7. Что реально доступно по правам роли (главный барьер)

Роль — единственное, что нас по-настоящему ограничивает, поэтому её границы выясняются
сразу и записываются, чтобы не наступать дважды.

1. **Перечень объектов** — из метаданных, это дёшево и не требует прав на данные:
   `meta catalogs`, `meta documents`, `meta accumulationregisters`, `meta accountingregisters`.
2. **Проверка доступа** — по одному объекту за шаг: запрос с `ПЕРВЫЕ 1` и явным перечнем полей.
   Отказ («Недостаточно прав») — это результат, а не сбой: он записывается.
3. **Итог** — таблица «объект → читается / отказано» в `docs/company/STAND_NOTES.md`.
   Дальше расширение доступа — разговор с администратором, а не наши эксперименты.

Не пытаться проверять доступ «пачкой по всей базе»: это сотни вызовов и лишняя нагрузка.
Один объект — один шаг, и только те объекты, которые нужны для текущей задачи.

## 8. Первая задача — одна и маленькая

Один объект или один модуль. Не «осмотреться по всей базе». Результат — в `map/INDEX.md`
и в заметки. Цель дня: доказать, что канал работает и что мы умеем останавливаться.

## 9. Чего в первый день не делать

- не выгружать конфигурацию «чтобы осмотреться» (отдельный согласованный шаг, §10);
- не выполнять отчёты и вообще код конфигурации;
- не читать модули целиком;
- не писать в базу ничего, включая пометки на удаление;
- не ходить в СУБД и не просить к ней доступ;
- не ставить на VM ничего, что не нужно для задачи: машину видит администратор.

## 10. Чтение модулей: одноразовая выгрузка (когда понадобится)

Текст модулей через COM **не читается** — нужна выгрузка конфигурации в файлы, по согласованию:

```powershell
ssh <vm> "& 'C:\Program Files\1cv8\<версия>\bin\1cv8.exe' DESIGNER /S'srv\база' /N'админ' /P'пароль' /DumpConfigToFiles C:\1c-bridge\dump /Out C:\1c-bridge\dump.log /DisableStartupDialogs"
```

Дальше — поиск по файлам с ограничениями (совпадения лимитированы), чтение одной процедуры
по имени. Выгрузку **не тянуть** на VPS целиком: читать на месте по ssh.

## 11. Стоп-условия

- операция идёт дольше клиентского таймаута → остановиться, не повторять, сообщить;
- не хватает прав → сформулировать, что именно нужно, и остановиться;
- у людей на стенде что-то тормозит → прекратить немедленно;
- «стоп-кран» — завершение **сеанса 1С** из консоли кластера; убийство процесса агента
  серверный запрос не останавливает.
